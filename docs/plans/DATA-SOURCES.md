# Standpoint — Free Data-Source Catalog

_The canonical catalog behind [STANDPOINT-VISION.md](STANDPOINT-VISION.md). 93 sources scouted across every domain by a multi-agent research pass, each verified for auth + license and tagged by **epistemic tier**._

**Tier** = who owns the number. **`measured`** = *we* compute a defensible statistic in Python over raw observed inputs and own it (a SIGNAL, or the freight SPINE). **`context`** = someone else's cited value shown as-is, possibly-related, never a stated cause. Promotion `context → measured` is gated (see the vision doc).

**Totals:** 55 measured · 38 context  ·  auth: free-key 30, keyless 60, paid 3  ·  ✅ = already shipped + live.

> ⚠️ Several entries carry **license/cost caveats** surfaced by the adversarial review — see [the caveats section](#-license--cost-caveats-adversarial-review) at the bottom before building any of them.

## ⚠️ License / cost caveats (adversarial review)

_The critic flagged these as **not actually free / not cleanly reusable** for a public, commercial-adjacent site. Treat as blocked or needs-legal-review until resolved — do not ship on the honesty brand without clearing these:_

- ACLED (P4, flagged free-key in plan) — As of the 2025 access-model change, commercial entities may not use ACLED without a corporate license, and Standpoint is a public flagship project that could be read as commercial. ToS also prohibits creating any product that is a 'functional substitute' or that allows 'reverse engineering of the underlying dataset.' Storing only derived z-aggregates is the right instinct but the COMMERCIAL-USE question is unresolved, not merely a republication caveat. Treat as genuinely at-risk, not 'free-key with a footnote.' Prefer UCDP GED (truly open) as the conflict spine and drop ACLED, as the plan half-suggests.
- FRED third-party series (P3) — Confirmed: FRED's API ToS prohibits redistributing third-party PROPRIETARY series (UMich, S&P, ICE, etc.) even derived, for commercial use, without the data owner's written permission. The plan's 'compute our own anomaly, never the raw number' is NOT a clean carve-out for those series — a transform of a proprietary series can still be a derivative. The plan's restriction to public-domain series (Treasury/Fed/BLS/EIA) is the only safe path; the plan states this but still lists FRED broadly as 'free-key' — it's free ONLY on the public-domain subset, and that boundary must be machine-enforced (allowlist of series_ids), not a comment.
- GDELT raw 15-min GKG (P0 baseline / news_geo) — Not metered, but the 'compute our own scalar from the raw 15-min GKG stream' approach is a hidden bandwidth/compute cost: ~2.5TB/yr, ~17-30MB per file x 96 files/day ≈ 1.6-2.9 GB/day of raw download to reconstruct daily theme counts inside an Action. That is not 'small payload' and can trip Action time/egress. The existing DOC-API 429 is already documented. Practically this means the raw-GKG ownership claim is far heavier than the current DOC-API path — flag the cost, don't assume it's free-in-effort.
- OpenAQ v3 (P5/frontier) — Free key, but rate-limited (docs indicate ~60 req/min, possibly lower defaults). Per-station anomalies across hundreds of port/city tiles is thousands of requests; a naive weekly pull will hit 429s. Workable only via bbox/aggregate endpoints, not per-station loops. Free, but operationally constrained.
- IOM DTM (P5) — ToS is non-commercial AND explicitly 'no right to create derivative works' and 'no redistribution.' For a commercial-adjacent site this is a real flag, not just attribution. The plan flags it but still schedules it; given the brand's zero-tolerance for ToS slips, DTM should be cut or replaced by UNHCR (CC-BY) which already covers displacement.
- Copernicus EMS / GloFAS direct + CEMS-FLOODS + GRACE-FO/GES DISC + DAHITI (P4/P5) — All require free accounts/keys AND several carry non-standard licenses (CEMS-FLOODS 'free but not a standard open licence'; DAHITI 'free for the user community' = registration-gated, attribution-required, community-scoped). 'Keyless/free' is overstated; these are registration-gated with reuse caveats that need per-source review before they count as zero-friction free.
- TeleGeography submarine cables, OpenSanctions, Cloudflare Radar, GPSJam, Global Fishing Watch (P4) — all CC-BY-NC or NC-restricted. Fine WHILE non-commercial, but the plan repeatedly leans on 'Standpoint is non-commercial' for a repo that is publicly positioned as a flagship demonstration. If the site is ever positioned as proof-of-commercial-capability or monetized, this whole NC cluster flips to non-free simultaneously. Name this single shared dependency explicitly: a large fraction of the context ring rides on a non-commercial determination that is not obviously safe.
- GHS-POP/WorldPop/Sentinel-5P/OISST (P5) — license-free (CC-BY), but 'free' hides that the GLOBAL products are multi-GB (uncompressed GHS-POP ~33GB; WorldPop ~200k TIFFs) — free to download, NOT free to process inside a free static-infra Action. The cost is compute/disk, which the zero-marginal-cost framing elides.
